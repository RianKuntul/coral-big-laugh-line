One hilarious line, written by a program: a smart fridge asked what
the household needs answers with a shopping list, a restraining
order, and a photo of its owner eating ice cream at 2 a.m. — the
appliance is snitching.

## Run

```sh
node main.ts
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to
`/output/entry.txt`), after self-validating the gate: exactly one line,
1–200 characters, no trailing newline.
